# MusaCAD Web

MusaCAD'in resmi ürün tanıtım web sitesi.

## İçerik
- Gerçek MusaCAD uygulama ekranları
- Mobil CAD özellikleri
- Çok disiplinli proje kontrol yaklaşımı
- Gandalf AI etkileşimli tanıtım demosu
- Geliştirici biyografisi
- Bireysel, profesyonel ve kurumsal lisans bölümleri
- Etkileşimli katman ve ihtiyaç özeti araçları

## Dosyalar
- `index.html`
- `styles.css`
- `script.js`
- `assets/musacad-logo.svg`

Uygulama ekran görüntüleri ana MusaCAD deposundaki gerçek ürün varlıklarından gösterilir.
